# Cloudflare Pages 部署 EdgeTunnel 并接入 v2rayN

## 1. Fork 项目

打开 [cmliu/edgetunnel](https://github.com/cmliu/edgetunnel)，点击 **Fork**，将仓库复制到自己的 GitHub 账号。

## 2. 部署到 Cloudflare Pages

进入 [Cloudflare Dashboard](https://dash.cloudflare.com/)：

1. 打开 **Workers & Pages → Create → Pages**。
2. 选择 **Connect to Git**，授权 GitHub。
3. 选择自己 Fork 的 `edgetunnel` 仓库。
4. 按项目 README 配置构建参数。
5. 在环境变量中添加管理员密码：

   | Name | Value |
   | --- | --- |
   | `ADMIN` | 自定义强密码 |

6. 点击 **Save and Deploy**，等待部署完成。

## 3. 绑定 KV

进入 Pages 项目：

**Settings → Bindings → Add → KV Namespace**

选择或创建 KV 命名空间，将变量名称设为：

```text
KV
```

保存配置，并按控制台提示重新部署。

## 4. 绑定自定义域名（可选）

进入 **Custom domains → Set up a custom domain**，输入自己的子域名，并按照 Cloudflare 提示完成 DNS 配置。

例如：

```text
https://tunnel.example.com
```

等待域名状态正常后，访问：

```text
https://你的域名/admin
```

使用部署时设置的管理员密码登录后台。

## 5. 获取订阅链接

在 EdgeTunnel 管理面板中查看节点及订阅配置。

复制项目实际生成的订阅地址。订阅路径和格式可能随项目版本变化，**不要直接套用其他教程中的示例链接**。

## 6. 导入 v2rayN

下载：[v2rayN 官方 GitHub](https://github.com/2dust/v2rayN)

1. 打开 v2rayN。
2. 进入 **订阅分组设置**，添加订阅分组。
3. 填入订阅地址并保存。
4. 执行订阅更新。
5. 选择需要使用的节点。
6. 启动代理，并测试网络连接。
